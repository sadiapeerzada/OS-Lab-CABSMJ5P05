WEEK 1 - C PROGRAMMING / OPERATING SYSTEM BASICS

Programs included:
1. CPU Time Conversion
   Converts CPU burst time in seconds into HH:MM:SS.
   Concepts: division (/), remainder (%).

2. Process Type Identification
   Prints "System Process" for an even PID and "User Process" for an odd PID.
   Concepts: modulus (%), if-else.

3. Context Switch Overhead
   Calculates total overhead using:
   Total Overhead = Number of Processes × Context Switch Time
   Concept: multiplication (*).

4. Resource Distribution
   Calculates equal printers per user and remaining printers.
   Concepts: division (/), remainder (%), if-else.

IMPORTANT:
- These programs use integer input.
- Compile each .c file separately.
- Example with GCC:
  gcc 01_cpu_time_conversion.c -o cpu_time
  ./cpu_time

Practice:
Try changing the input values and predict the output before running the program.
